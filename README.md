## 📌 Featured Projects

### 🔹 **GAN-Based Sensor Pattern Noise Restoration**
🛠 *Sensor Pattern Noise (SPN) is a unique camera fingerprint caused by manufacturing imperfections, enabling forensic identification of image sources. However, lossy compression degrades high-frequency SPN components, complicating camera source identification. This project introduces a conditional Generative Adversarial Network (cGAN) to reconstruct SPN from compressed images. Achieved significant accuracy improvements: 89% at Q=90 (+5%), 72% at Q=60 (+16%), 51% at Q=30 (+10%). Implemented specialized discriminator architecture and progressive transfer learning across compression levels.*

🔗 [Repo](https://github.com/dobrematei14/GAN-based-Sensor-Pattern-Noise-Restoration)

### 🔹 **RAG-Based University Information System**
