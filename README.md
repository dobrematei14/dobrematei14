## 📌 Featured Projects

### 🔹 **GAN-Based Sensor Pattern Noise Restoration**  
🛠 *Sensor Pattern Noise (SPN) is a unique camera fingerprint caused by manufacturing imperfections, enabling forensic 
identification of image sources. However, lossy compression degrades high-frequency SPN components, complicating camera 
source identification. This proposal introduces a conditional Generative Adversarial Network (cGAN) to reconstruct SPN 
from compressed images. The generator, conditioned on compressed inputs, restores missing SPN details, while the 
discriminator distinguishes between recovered and ground-truth SPNs. A multi-loss function combining reconstruction, 
correlation, and adversarial losses ensures forensic accuracy and visual plausibility. This approach aims to advance 
image forensics and enhance the reliability of digital evidence.*
